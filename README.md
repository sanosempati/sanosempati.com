# sanosempati.com

Portfolio one-pager untuk **Sano Sempati**, diadaptasi dari struktur dan bahasa visual [danielherzog.design](https://www.danielherzog.design/).

## Menjalankan lokal

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- Tailwind CSS v4
- Framer Motion
- Lenis (smooth scroll)
- Satoshi (Fontshare)
